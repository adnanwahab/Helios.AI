BUILT TO BE CLEAR

A tool can be ready
before a service is connected.

Browser tools run here without a shared database. Their local records stay in this browser unless you export or explicitly share them.

Shared tools require the service shown on their card. A configured worker connection does not mean a worker is running; research rooms show actual active leases.

“Setup needed” means you can still open the interface and keep a draft. A saved vote, shared revision, sent request, or GitHub PR is confirmed only by its backend.
