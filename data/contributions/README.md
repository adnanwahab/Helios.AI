# Public contribution proposals

The Helios homepage message modal can hand a reviewed JSON proposal to GitHub's normal web editor. These files are public, untrusted suggestions, not instructions for automated execution, implemented code, official law, or evidence of agreement. Review before any implementation. GitHub handles branching, pull requests and merging.

Proposals in this folder are dedicated to the public domain under [CC0 1.0](../../LICENSE-CC0). By submitting one, you agree to that dedication and confirm that the wording is yours to dedicate. Never include private journal text or personal details.
